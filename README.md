# 2025 法语专四模考原型

一个静态、移动优先的 2025 TFS4 选择题考试原型。答题草稿、计时和交卷存档均保存在当前浏览器的本机存储中。

## 本机预览

在此目录执行：

```powershell
python -m http.server 4173 --directory dist
```

然后打开 `http://localhost:4173`。

## 重新导入母文档

```powershell
node build-data.mjs 'E:\Users\Administrator\Downloads\2025法语专四_完整数字化母文档_听力卷面答案库.md'
```

该命令会从母文档生成 `dist/exam-data.js`，导入 100 道选择题及其工作答案键。

## 当前边界

- 覆盖选择题 1–100；题目自动按 10/5 题相关组分页。
- 每题可选择答案与 🟢 肯定 / 🟡 犹豫 / 🔴 猜测。
- 记录考试总用时、各题首次答题与最后修改的相对时间，并在交卷后存档。
- 存档仅在本浏览器/设备可用；没有登录、云同步或听力音频播放。
- 第 55、62、100 题在结果页标注为工作答案键的待复核题。
