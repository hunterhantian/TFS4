# 数据目录

`2025-reference-answers.json` 为用户在2026-10-26验收意见中指定采用的官方参考答案，来自已提供答案PDF第1页，记录源文件SHA-256与全部100题答案。61=A、62=B；导入器优先读取此文件，不再用母文档旧推导答案覆盖它。

`2025-candidate.json` 仍为候选题库，未完成正式内容导入/审核；答案状态为reference_confirmed，来源为2025-reference-v1。61/62答案修订至版本2，其他为版本1。知识点关联尚未审核，不能用于正式推荐。

`answer-audit.json` 保留61/62从D改为A/B的决定与来源依据；当前100题差异为零，旧差异见Git历史。55/100采用参考答案C评分，不再列为待复核判分项；母文档的歧义说明保留在历史文档，不改变本次用户指定的判分口径。

`source-manifest.json` 保存资料路径、大小、哈希和页数。只有答案资料由用户确认采用；解析PDF的官方出处仍未核实，听力解析缺失，留待内容阶段处理。源文件和个人答题卡不进入Git。

31–40为Part III词汇完形，41–80同为Part IV语法，81–100为Part VI阅读。听力三选项为正常结构，阅读保留完整五题材料；听力时间戳尚未整理。

生产导入必须显式接收正式审核批次，拒绝dataset为fixture/candidate的数据。当前不提供生产导入命令。测试夹具位于tests/fixtures，不混入此目录。
