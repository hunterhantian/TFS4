# 数据目录

`2025-candidate.json` 是由现有原型生成的候选数据，不是正式题库。所有答案均保留工作答案来源；55/62/100 原待复核标记及 61/62 的资料差异必须保留。正式发布需在 D16–D22 完成来源确认和内容核对。

`source-manifest.json` 记录本机资料位置、文件大小、SHA-256 和页数，不含个人答题卡识别结果。资料文件留在仓库外。

`answer-audit.json` 是已提供答案 PDF 第 1 页与原型全部 100 题的逐题对比结果，未覆盖原型答案。

31–40 属于 Partie III 词汇完形材料；41–80 同属于正式 Partie IV 语法，原型两个语法组不是两个正式 Part。听力 1–20 只有 A/B/C 三项，是卷面结构，并非缺失 D。现有阅读有四个完整五题材料。听力时间戳与题组引用尚待 D22/D27 核对，不能视作完整听力材料导入。

生产导入必须显式接收正式审核批次，拒绝 `dataset: fixture` 和 `dataset: candidate`；当前不提供生产导入命令。

两处答案PDF的SHA-256相同；两处试卷PDF均为18页但哈希不同，因此清单分别登记，不当作同一二进制文件。个人答题卡及空白答题卡不收集哈希到公共清单。
