# 历年解析 Markdown

本目录保存 LlamaParse 已完成的解析结果。`fast` 版本覆盖 2005–2019、2021 年 5 月/6 月、2022–2025，共 22 个 PDF、1850 页；2023 年的主版本与补充版本分别保留。`2025/v1` 是此前的 cost_effective 版本，作为历史对照保留。

这些 Markdown 是解析原文，不是校对通过或官方答案真值。`pages.json` 保存逐页文本，`provenance.json` 保存来源哈希、解析参数和状态。未经后续审核，不得用解析中的答案覆盖题库答案、解除内容阻断或直接发布知识点分类。

真题和答案 Markdown 位于 `data/stage2-handoff/md-batch/`。该交接包包含 21 个实际场次：2005–2019、2021-05、2021-06、2022、2023、2024、2025；没有独立 2020 卷。
