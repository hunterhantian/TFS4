# Sol low r2 候选题库与知识树：本地验收

基线：`stage-2-question-bank` 的 `2fe340548332b2717ebe0b66624e9ff30520093e`。本交付是登录用户可访问的只读候选浏览入口，不导入正式答案或改写历史考试、成绩和现有题库。源快照与搜索索引由同一进程内的数据生成，登录鉴权后访问；重建快照后需重启服务以加载新版本。

## 启动和重建

在项目目录，使用 Node 24 与 pnpm 11.25.0：

```sh
pnpm install --frozen-lockfile
node scripts/import-synthesis.mjs ../TFS4-knowledge-tree-sol-low/r2
node scripts/manage.mjs seed
RSZ_ADMIN_PASSWORD='自行设置的本地密码' node scripts/manage.mjs create-admin reviewer
node server/main.mjs
```

导入脚本会与仓库 `data/stage2-work-results-20261031-update/file-manifest.json` 对比三个源文件的 SHA256、检查题目 ID 及数量，再原子替换 `.local/synthesis/snapshot.json`。重复执行得到同一字节快照。源目录可作为第一个参数，目标路径可作为第二个参数；系统默认读取上述 `.local` 路径。源目录不在本机时，可按两个成果 README 恢复归档。快照及测试数据库均被 Git 忽略；迁移到其他环境需重新导入。原记录中的绝对路径是历史来源标识，不保证该路径在其他设备可直接打开。

访问 `http://127.0.0.1:4174/`，登录后选择“真题题库”或“知识树”。本地测试账户只用于隔离库，不用于线上。现有生产数据库未接触。

## 从 GitHub 归档恢复题库数据

干净检出没有 `.local/synthesis/snapshot.json`。下面从仓库的增量归档提取三个 r2 文件，校验并生成本地快照；先完成此步骤再运行 `pnpm test` 或打开题库、知识树。整个过程只写入被忽略的 `.local` 目录：

```sh
mkdir -p .local/synthesis-restore
cat data/stage2-work-results-20261031-update/archive/tfs4-update-20261031.tar.xz.part* > .local/synthesis-restore/update.tar.xz
shasum -a 256 .local/synthesis-restore/update.tar.xz
# 应为 ca4b698fb701b181d739f501172d59ca2349b3ab44b1cc664288cb2c9177139e
tar -xJf .local/synthesis-restore/update.tar.xz -C .local/synthesis-restore TFS4-knowledge-tree-sol-low/r2/knowledge-tree.json TFS4-knowledge-tree-sol-low/r2/tree-item-mappings.json TFS4-knowledge-tree-sol-low/r2/answer-reference-view.json
node scripts/import-synthesis.mjs .local/synthesis-restore/TFS4-knowledge-tree-sol-low/r2
```

上述增量归档与生成的快照已在本机复核；完整恢复所有工作成果仍应按两个成果 README 操作。此步骤不需要账户或生产数据库。

## 口径与限制

- 21 场共 2520 项（每场 100 道选择题及 20 个动词空），20 个年份，2021 年含五月和六月，无 2020。空年份选择为全部；多选为并集。
- 902 节点、881 叶。节点计数是所选年份映射到该节点及后代的不同题目数，包含候选和缺源；不代表已审核数，也不是判分可用数。
- 源映射中的材料状态：1748 候选、413 听力不可作答、351 待复核、8 原始缺源占位。8 项均有后续恢复题面记录，其中 2018 听力题仍缺可核验听力内容。不同轴状态不可相加或当作正式通过。答案视图有 420 条仅来源字母、未核音频；其余仍按原记录逐项显示。
- 搜索遍历原始分层映射、答案记录和相关节点字段，包括解释、证据、条件、节点定义与祖先路径；大小写、重音、Unicode 兼容形式和连续空白归一化。匹配字段与片段用于定位，详情保留完整原始结构。节点筛选依据 r2 自带映射，未映射项不会凭猜测挂接。
- 答案视图是分层参考，非正式判分答案。多参考与条件分支不压成一个确定答案；原始层、来源、修订和未解决状态保留在详情。

## 本轮验证

- 清单校验通过；同源两次导入生成相同 SHA256。原始交接基线 139 文件、42 文档、452 页校验通过。
- 70 项自动测试全通过，包括新接口的管理员权限、2520/902 数量、2021 与 2023 联合筛选、空选全部、无 2020、两场同题号、节点计数、中文解释与定义、法语重音及无结果；验证读取不写入审核和报告。
- 桌面浏览器实际登录并操作了多选 2021+2023（360 项）、定义搜索、节点下钻、答案详情；390×844 移动视口检查了解析搜索、无结果、清除、2018 缺源恢复详情，页面宽度与视口同为 390px。
- 仓库原有 2023/2024 候选文件的证明清单记录 CRLF 字节，仓库检出为 LF 导致哈希测试失败；`.gitattributes` 明确要求这两个文件以 CRLF 检出后通过，内容不变。没有把历史测试报告当作本轮结果。

## 2026-11-01 题库展示修订

主页将“真题题库”和“知识树”拆成两个入口。题库可同时多选年份与题型，任一筛选未选表示该项全部；搜索仍覆盖分层内容与节点。按场次、题型和材料来源及文本合并，同一篇完形、阅读或动词填空显示完整文章与全部小题，答案与解析在用户展开后按小题读取；缺源和缺空位状态保留。搜索命中某小题时返回整篇并标记命中题号和字段。全部年份共有 1596 道展示单元，底层仍为 2520 项。新接口对空筛选、多年份、多题型、同篇合组、缺空标识、答案隐藏和搜索关联做了测试；原只读接口和历史数据未改动。

## 小题展示修订

按用户后续决定，题库列表改为逐小题展示；前述“同篇合组展示”和 1596 展示单元的说明仅为上一版历史。当前全部 2520 小题各自显示，带材料的小题可展开原文、参考答案和解析。完形和动词填空在能可靠识别编号时展示原文中该空所在句；不能可靠定位时保留原题片段或缺空提示。搜索与年份、题型多选按小题生效，知识树下钻亦按小题显示。原始来源与答案未改写。

## 知识树三级浏览修订

首页“知识树”入口使用左右三列逐级展开。初始仅列大类；选择大类显示规则族，选择规则族显示具体知识点。仅第三层点击加载下方相关小题及节点定义；切换上层或年份、搜索不重新加载已显示的题目。筛选变更时明确提示旧结果的年份，须重新点击第三层节点。名称、定义、别名搜索保留匹配节点的祖先路径；手机窄屏可左右滑动三列。节点计数仍是所选年份中相关的去重小题数，包含候选及缺源。

## 主界面精简

主页只保留五个常用入口（管理功能依账号权限显示），旧导入、旧客观题知识树及批次、内容审核、关联维护等测试页面不再挂载；原考试、报告、历史数据和服务端兼容接口保留。主页及保留页面沿用深色与存档语义配色，桌面与 390px 手机视口检查过布局。

## 普通用户只读访问

按后续要求，真题题库和知识树现对所有已登录账号开放；原文中的“管理员专用”描述属于旧版本。两个页面共享同一候选快照，保留非正式判分和来源状态说明。未登录用户仍不能访问；管理员接口、账号管理及所有考生存档仍限管理员。历史成绩仍按账号隔离。
