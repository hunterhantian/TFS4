## 6. 环境与可复现命令（Linux/Web）

Node.js **24.x**、pnpm **11.25.0**、Fastify5、better-sqlite3。先确认`node --version`，再执行：

```bash
pnpm install --frozen-lockfile
node scripts/stage2-web-bootstrap.mjs --verify-only
pnpm test
# 首次只在全新工作区执行；已有数据时脚本会拒绝覆盖
node scripts/stage2-web-bootstrap.mjs
node scripts/stage2-knowledge-tree-review.mjs
```

知识树服务监听`127.0.0.1:4181`。若Web提供端口预览，按其环境配置访问；不要默认容器localhost可从用户电脑直接访问。脚本在`.local/stage2-knowledge-tree/知识树体验账号.txt`生成新的随机管理员，仅用于该工作区，不提交或复用生产账号。没有浏览器工具时先验证API/数据，不伪造视觉通过。

bootstrap先校验139个载荷文件的SHA256（另有清单自身），复制交接数据到`.local/stage2-web/`，在空库导入三卷内容及审核，再在独立副本导入360项分类、复建277/83知识树并独立核验。它不恢复真实用户、历史考试、旧38题校准或所有旧目录。新空库没有旧业务记录，受保护表数量/目录revision与本机全历史库不同是预期；三卷内容/分类及汇总必须一致。本机旧库“源不变/64受保护表”的历史证明不由这个空库替代。

脚本默认固定输出路径；为保护已有工作不提供自动删除/覆盖。再次验证用新工作区。`--verify-only`可重复运行。浏览器回归需自行安装可用Playwright/Chrome；原脚本中的Windows包缓存路径不能作为Web依赖。

新年份原始提取（仅生成草稿，不给通过状态）：

```bash

```

`stage2-pilot-content.mjs`、`stage2-proofread-pilots.mjs`、`stage2-objective-labels.mjs`和最小导入脚本目前有三卷/360项固定假设。它们不是能直接泛化到任意年份的自动标注器；量产前需显式改造并测试，不得改年份参数就宣称新卷已校对。
