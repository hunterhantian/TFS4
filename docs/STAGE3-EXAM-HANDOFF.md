## 服务器核验与访问

上传前确认：服务器 `/home/ubuntu` 所在文件系统约 59 GB，剩余约 51 GB；私有源目录此前不存在。私有源目录顶层现有 **22 个文件**（21 个源音频 + `manifest.json`）；子目录 `converted-mp3-v1/` 留有三份经校验的MP3转换件、转换清单和部署脚本。公开目录 `/var/lib/ruanshizi/media/stage3/` 包含21个规范名MP3和一个公开 `manifest.json`。原有2025单文件路由保持不变。

登录服务器后由 `ubuntu` 用户核验：

```bash
ls -lah /home/ubuntu/stage3-audio-v1
cat /home/ubuntu/stage3-audio-v1/manifest.json
find /home/ubuntu/stage3-audio-v1 -maxdepth 1 -type f \( -iname '*.mp3' -o -iname '*.wma' \) | wc -l
```

音频已可通过 Nginx 静态路径读取，URL规则为 `https://193.112.151.236/media/stage3/{年份或场次}.mp3`；例如 `https://193.112.151.236/media/stage3/2023.mp3`。Nginx配置备份位于服务器 `/etc/nginx/sites-available/default.before-stage3-audio`。当前URL是公开、无鉴权的；如未来不再允许公开，应从Nginx移除此location并撤掉公开副本的读取权限。Range（206）已验证可用。
