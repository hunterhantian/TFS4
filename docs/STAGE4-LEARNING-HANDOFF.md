## Stage 4 范围与顺序

1. **D31 证据与事件衔接：**盘点已有事件和报告，设计并实现 Stage 3 新版选择题的作答／错题事件来源、题目与答案版本、用户归属、幂等约束。未作答、动词待评、旧版未判分报告、缺答案或不可靠来源不能伪装为确定错误；不改写现有报告或历史成绩。历史数据是否补录需有可追溯规则，不默认批量回填。
2. **D32–D33 查看与筛选：**实现个人错题本，按年、题型、Part、知识点及信心筛选，展示首次／最近／历次证据；单次错误不等于掌握度结论。已答对但猜测或犹豫与确定答错分别呈现。
3. **D34–D38 练习闭环：**原题重练、可靠同知识点新题、练习与原错题关联、Markdown学习包导出、新错误进入错题本；阅读和完形保留材料与题组。知识点作为关联核心，题型用于分组与训练顺序，不做全库逐对标签。
4. **D45–D47 延后混合验证：**先确认样本、去重和材料完整规则，支持后续混合测试且不提前泄露考点。题目或关联不足时明确展示；不将候选关联冒充已核验关联。
5. **知识体检与进步证据：**按知识树展示可追溯样本与不同练习类型的变化；阶段5综合能力分数、权重及预测仍需独立确认。各开发项目与验收状态以开发清单为准。
