# Stage2 两轮生产与知识树审计流程

2026-10-30 用户确认的新流程。适用当前客观题校对、初标、审计与知识树合成阶段。与旧文档“先三源一致才能初标”冲突时，以本文件为准；原始材料、历史产物及既有版本不覆盖。

## 1. 阶段目标与职责

第一轮：GPT-6.1 Terra / high，采用2023实验E的方法，仅依据真题独立解题、生成解析并初标，输出候选。

第二轮：由用户安排Sol执行审计、裁决与知识树合成。Sol版本及推理等级由实际任务配置记录，本流程不擅自固定。完成审计前，第一轮结果不作为正式判分答案或已审核检索题。

E是方法参考，不是正确标签模板；它在第76题、动词17等仍有未裁决分歧。不得复制E答案或把本次主观质量分作为验收准确率。

## 2. 批次准备

1. 按实际sitting列场次，2021五月/六月分开，无独立2020时不补造。每批建议2–3场次，共用同一目录版本；按批审计后再扩展。
2. 冻结真题MD、已保存逐页文本、题号规则和输入SHA256。共同目录只包含节点ID、名称、定义和边界，不携带已标题目、答案或旧解析；记录目录哈希。目录可能提供考点线索，因此称“单源独立作答”，不夸称完全无提示闭卷。
3. 第一轮使用未读过该卷答案/解析的新聊天，不注入旧审计错题提示。将答案MD、解析MD和旧标签隔离到第二轮。曾接触这些内容时记录上下文污染，不声称独立评估。
4. 指定独立输出目录、模型/推理配置，记录实际UTC起点。保留源MD字节，不批量格式化，不回看PDF、不重跑OCR。

## 3. 第一轮：Terra high 真题校对、独立解题与初标

### 3.1 真题结构校对

逐题确认题号、题干、完整选项、材料题组和动词空。检查HTML表格、跨页段落、题号标点及重复选项标签；考试说明编号不作题号。重复字母用“原标签+选项位置”定位。原文异常单独记录，推测修订另存候选，不能无依据改写来源。

此处“校对”是对真题内部结构、题面完整性和语义异常的检查，不是与答案或解析交叉校对。记录源行号/页号/区间与原文片段。

### 3.2 自主作答与解析

选择题及动词空逐项解答；每个动词空独立映射，答案保留“实际填入空位的形式”，避免重复主语或介词。解释决定答案的规则或材料句段；竞争规则或多解时给出替代读法及理由，不强迫单一答案。

无音频/允许听力证据时，听力记不可判定，不编造答案、事实或录音；可仅标题干任务。作文、看图、听写不进入本阶段知识树。不得读取独立听力原文、翻译或音频。

识别题面删除线、内嵌答案等可能泄露；明确标记影响项目，不将其当作独立答题准确率样本。不可判定项的独立样本资格必须为false。

### 3.3 知识点初标

每题一个主知识点、题型和决定性依据。依据来自真题及本轮自主解析，不使用答案MD或旧解析。先判断解题依赖的具体规则，再选择准确叶节点，不按词汇/语法等大类直接分桶，不把同词出现等同同考点。

现有叶不适配则单建候选新叶，附定义、适用/排除边界、代表题及来源；不得用“其他/待定”作为有效分类，也不因规则名称相近就重复建叶。

答案有争议时可以给出带条件的分类候选；不同解读对应不同主考点时须记录分支，不把某一读法标为无条件确定。听力任务分类、待核候选及一般初标分别计数，均不直接计入正式可用题。

### 3.4 第一轮交付与完成条件

覆盖每场实际全部客观题；2023为100选择题+20动词空，其它年份按真题结构核对，不硬套数量。无解或来源不足也要有独立记录及理由。

产物：完整content候选、逐题review.json/md、initial-annotations.json、candidate-new-leaves.json、来源/目录清单与哈希、timing.json、validation.json、summary.md。

每条包含稳定itemId、题型、题面/选项/材料引用、答案候选、解析、主知识点、归类依据、源区间、内容与分类版本、争议及审核状态。与现有content-v4协议适配，不自行用同名空壳冒充协议完整文件。

机械检查必须覆盖缺题、重复ID、动词空映射、来源可定位、标签/选项位置、状态与样本资格一致。机械通过不等于语义通过；仅生成文件、题号和非空标签不算完成逐题工作。

## 4. 第二轮：Sol审计与裁决

1. 核验第一轮输入哈希、题目覆盖、材料完整性及版本；保留第一轮原件，审计修订写新版本。
2. 逐题审阅答案、解析和主知识点是否互相支持；特别检查“答案相同但理由错误”“节点相关但不是主考点”“合法形式却不合语境”。审查所有待核、新叶、跨型归类和来源异常，不只抽查最容易的题。
3. 审计可读取对应答案MD、解析MD及其版本，交叉检查来源。它们是对照证据，不是无误金标；解析缺失本身不否定题面推理，答案/解析冲突不以多数一致自动裁决。决定应写清可核验证据及排除其它解释的理由。
4. 保留审计通过、修改后通过、退回/阻断、听力任务候选等不同状态。无法可靠裁决的题目留待核，不计正式知识树可用题；不要求用户逐题批准。
5. 审计直接看到初标的，称审阅/裁决，不称独立盲标。若评测独立分类质量，另建未见初标上下文，先保存原始判断再比较；不能复制第一轮结果充当独立复核。
6. 纠正答案或题面会改变考点时，同步重审分类及受影响材料。正式判分答案的采纳、线上发布仍是独立操作，不随审计自动发生。

产物：逐题audit.json/md、修订内容/分类、分歧与裁决台账、通过/待核集合、目录变更建议、验证与计时。每项修改有旧值、新值、理由、来源和版本。

## 5. Sol合成知识树

仅将审计通过的归类加入本批审核知识树；候选新叶先裁决边界、重复与层级，再纳入目录新版本。第一轮任务标签和待核项保留候选视图，不混入可用题数。

同具体主知识点聚合，题型用于分组；同一规则跨题型共享知识点身份，父节点只汇总。工作目录最长4层、简单分支3层，变更须记录影响范围。不得用共同父节点、辅助点或相同词语冒充同主考点。

按稳定题目ID去重，不累计重复版本。检查同叶正例及邻近叶困难负例、跨题型分组、材料完整性、分页/空分组和有效状态过滤。不得用同标签查询自证分类准确，不建设全库逐对配对标签。

产物：catalog版本及变更表、审核分类映射、候选问题清单、节点题数/题型汇总、集合检查和可复现验证报告。先在隔离测试环境合成，不自动合并main或上线。

## 6. 批次验收与成本记录

分别报告：实际覆盖、可独立作答、初标候选、审计通过、修改后通过、待核/阻断、听力任务、候选/采纳新叶及知识树可用题数。内容可用、可检索、可判分和用户验收不可混计。

第一轮、审计、合树分别记录实际起止和耗时，阶段交错则诚实合并。取得真实tokens/费用则报告，否则unknown，不按耗时推算成本。答案一致率与独立正确率分开，评估分母统一排除来源不足和已识别泄露，保留排除清单。

本次没有新设数值准确率门槛；审核证据不足不称量产达标，既有未通过质量门不因换流程自动通过。系统性错误先修订并重审影响范围，再扩批。

原始MD、交接哈希、Stage1基线、正式参考答案、考试快照、历史报告和成绩不覆盖或重算。账号、会话、数据库、备份、密钥不提交。当前仅改写工作流程，不启动批处理、审计、合树或部署。
