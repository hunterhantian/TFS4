# Stage2 剩余 MD 分批生产计划

确认日期：2026-10-30（北京时间）。用户已确认按本流程推进剩余资料的校对、标注与知识树匹配。本文件规定后续执行顺序；不是已完成记录，不改变现有金标门槛或阶段验收状态。

## 一、采用的方式

**收敛三卷基线 → 一套未见场次完整验证 → 每批2–3套，先完成真题/答案/解析三份MD联合校对，再批量标注 → 逐批验收与扩展。**

不先处理完所有剩余MD再验证分类，也不让每年独立发展一套知识点体系。校对和标注保持独立产物与版本；同一批共用冻结的知识树目录。

资料单元按sources.json中的实际考试场次（sitting）确定，不机械按年份计数。一套完整资料单元包括对应真题MD、答案MD和答案解析MD；缺失资料明确记录。2021五月/六月为不同场次，不补造2020资料。

### 三份 MD 校对门

每道进入标注的客观题，必须先建立三源对应关系：真题 MD 核对题面与材料，答案 MD 核对答案来源，答案解析 MD 核对解题理由与考点候选。三源一致后内容版本才可进入“可标注”；解析缺失、题面与解析不对应、答案与解析冲突或解析有明显推理/转写错误的题目，保留为校对候选，不进入正式知识点标注。解析是证据层，不能覆盖真题或答案原件。

## 二、执行队列

### 步骤1：收敛三卷基线

- 对2012、2013、2023共277题首轮独立复核的17项分歧逐项裁决，保留两轮原件、决定性MD句段和裁决理由；260项一致不自动等于金标通过。
- 核验高风险阅读、跨题型节点和知识点适用边界，必要时生成目录新版本，重核受影响题目。
- 单列审计83项候选；来源不足继续候选，当前60听力不突破来源限制。
- 完成金标及38个多题叶与相邻困难负例的集合质量检查，按领域/题型分别报告，不以标签一致性代替语义准确率。
- 记录Linux测试的2项历史CRLF/LF哈希失败及修复验证，不修改预期哈希来制造通过。

产物：基线/目录版本、独立审阅和裁决记录、候选问题清单、集合评估及实际测试报告。未满足条件时不宣告基线收敛。

### 步骤2：一套未见场次跑通全流程

- 从未参与当前目录设计的场次选择一套，先记录选择理由、输入文件及SHA256；不得将现有三卷或已用于校准的资料冒充未见卷。
- 开始前冻结校对规范、目录与质量评价规则；先判断现有三卷专用脚本的固定假设，必要时改造并测试，不能仅改年份参数即称已校对。
- 按“来源盘点 → 真题/答案/解析三源对应 → MD内容校对 → 三源冲突裁决 → 结构化校验 → 内容版本冻结 → 独立标注 → 复核/裁决 → 知识树查询验证”完整执行。
- 标注每题一个规范主知识点、题型、必要证据与复核状态。新点、缺口、竞争规则先进入候选，不强塞已有节点。
- 记录覆盖、候选、目录新增/变更、错误、实际耗时和可取得的调用成本；无法取得的成本注明未测，不编造。
- 按金标方案评估可追溯性、语义及集合质量。目录因该卷调整后，同卷再测是回归，不再作为独立泛化证据；必要时换另一未见场次验证。

产物：该场次完整处理链、质量摘要及继续/修订决定。质量依据不足的领域不扩展生产。

### 步骤3：每批2–3套，分阶段生产

1. 冻结批次清单、输入哈希、目录版本与工具版本。
2. 先完成该批全部三源MD校对：核对题号、题干、选项、材料题组、答案/解析对应与动词空参考边界；保存原文、修订及依据。
3. 结构化校验通过后冻结各卷内容版本。解析缺失或三源冲突逐题隔离，不将缺题卷冒称完整可用卷。
4. 仅对三源校对通过的题目批量标注，使用同一冻结目录；完成独立复核和分歧裁决，分别保存候选与通过项。
5. 通过已审核主知识点生成查询分组，检查节点集合、题型分组和材料完整性，不建立全库逐对匹配标签。
6. 形成批次报告，达到质量条件后进入下一批；质量下降或系统性问题出现时暂停扩批，修订并重核受影响范围。

### 步骤4：逐批验收与收尾

每批报告列出：场次、输入/输出哈希与版本、处理数量、内容可用/可检索/可判分数量、候选原因、目录变化、独立复核与裁决、质量分母与错例、测试、耗时/成本和Git提交。

工程测试、语义质量、答案采纳、用户验收和上线分别记录。最终按D16–D22、S2-R01–R17及G1–G5检查剩余项，不因批处理执行结束提前宣布阶段2完成。

## 三、校对与标注的版本规则

校对确定来源实际内容，标注判断题目所考知识点。标注发现题面问题时退回校对，新增内容修订版本；重核相关标签和证据，不能修改题面后无条件沿用旧标签。目录定义变化同样记录影响范围并重核。

原始MD及交接哈希基线不可覆盖，新产物写新版本/目录。独立审阅不看初标归属，保留真实原件后才解盲。知识点查询以同主知识点为核心、题型分组；共同父节点或相同词语不能冒充相同主考点。

## 四、范围与交接

继续只读现有MD及保存的逐页文本，不回看PDF、不重跑OCR/LlamaParse、不读取独立听力原文/翻译/音频。只推进选择题和参考可核验动词空；主观题保留历史，不纳入当前知识树生产。

不覆盖正式参考答案、Stage1内容、冻结考试、历史报告或成绩。只操作隔离测试环境；账号、数据库、备份与密钥不入Git。用户本次确认流程不等于授权合并main或部署。

每轮更新本计划的执行台账、开发清单及证据，提交到stage-2-question-bank或其任务分支。阶段状态以实际验证为准。
