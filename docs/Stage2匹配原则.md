# Stage2匹配原则

2026-10-28用户确认。本文为后续匹配与标注工作的最新原则；与旧文档中“同题型作为唯一默认入口”或逐对建立关联的描述冲突时，以本文为准。原则确认不表示界面与接口已经改造完成。

## 核心规则

**同知识点作为核心，题型作为分组和训练顺序。**

用户从知识树进入一个具体主知识点，展开后直接查看归属于该节点的多道题。题目按题型分组，不要求先选一道出发题才能看到整个知识点下的题目。选中某题后仍可查看归类依据或与另一题对照。

同一具体规范主知识点下的不同题型共享一个知识点身份，不建立“选择题版知识点”“填空题版知识点”等重复节点。上级节点只做汇总；共同父节点、共同辅助点或相同词语不能当作同一主知识点。

## 标注工作到哪里为止

日常标注以“题目 → 知识点归属”为单位，完成题型、一个规范主知识点、必要的题中依据及复核状态，保留来源和内容/分类版本。不能确定的归属保持待复核，不为了填满目录强行归类。

辅助知识点、具体考法、完整干扰项分析和针对每对题的比较解析不作为本轮每题强制增加的标注项目；只有解决实际歧义所必需时补充。已有历史分析保留，不因简化规则删掉证据。

**标注不延伸为题目与题目逐对配对、逐对打分、逐对撰写匹配说明。** 已标注题按知识点和题型查询形成题目列表。新增一道已标注并审核有效的题，只登记自身知识点归属及版本，由程序纳入对应分组；不重新标注同组所有题，也不为它重算全库两两关系。

仍保留必要的分类核验、来源检查和代表性正负例抽查，检查错误归类和查询逻辑；这是质量验证，不是额外建设全题库两两关系标注集。不得用简化标注为理由取消审核，或将未验证数据称作已经正式匹配。

## 页面与查询

1. 知识树的具体节点显示名称及可用题数，展开后显示多题列表。
2. 列表以题型分组；显示年份、题号、题干摘要，展开可见完整题面、材料及已有归类依据。
3. 节点题数按当前有效题目去重，不累计重复版本。某节点3题表示收录3道有效题；从其中一道出发时，其他题最多为2道，仍需排除重复原题。
4. 同题型用于先巩固；同知识点的不同题型在独立分组中用于后续应用，不额外创造跨题型知识点或逐对迁移标签。
5. 来源、审核状态与版本条件继续生效；没有可用题或某题型无题就明确显示空分组，不凑数。待审核、退回、分类失效的题不计为可用匹配题。
6. 题目知识点不变时，新增同组题只更新查询结果；知识点定义或题目内容改变时，仍按版本及影响范围重新核验，不能无条件沿用旧分类。

从本次确认起，只讨论和推进客观题知识点匹配；包含选择题及有明确可核验参考答案的动词填空。作文、看图及其他主观任务不进入后续匹配标注和知识树展示；此前处理结果只作历史留存。

本轮工作目录采用最长4层、简单分支3层，已形成218节点/190叶节点；这是基于三卷的可修订工作目录，不保证21套量产前无需校准。
