# 动词填空：结合上下文的判分设计

状态：设计待实施
日期：2026-11-03

## 目标

用户填写文章空线中缺少的内容，系统根据该空的标准答案、前后原文和已确认的其他答案形式判断结果。用户确认的当前答案版本是标准答案；判分准备阶段只从中整理空内形式，不静默修改其原文。目标是避免把题面已经出现的内容重复要求用户输入。

目前本地 `verb-exact-v1` 使用标准答案和已列出的其他形式直接比较，已经复现空内正确内容被判错；本设计尚未实现，不能因此声称现有程序已支持上下文判分。

## 一、逐空数据

每一道空单独保存：题号与场次、题面和材料版本、空线位置、空前与空后上下文、用户指定的标准答案原文、对应来源版本、已确认的空内标准填写形式、已确认的其他可接受形式、证据及处理状态。标准答案保留完整原文，实际判分使用经过逐项确认的空内形式。

题目提示中的括号动词、文章正文、排版标记和可能错误插入的上下文提示分别处理。空线必须唯一定位；材料缺字、题号不明或答案与题面无法对应的项目标记为待核对，不自动生成答案。修订形成新版本，记录依据、生成方式与确认状态。

## 二、从上下文整理可接受形式

1. 在冻结的完整文章中定位目标空，识别紧邻空线的有效正文，剔除仅作为题目提示的原形、题号和HTML标记；记录定位证据。
2. 标准答案包含题面已有的主语、代词、介词或副词时，结合句子生成只填空内内容的候选形式。要逐题判断该成分在正文中是否真实存在，不能看到括号或相同词就全局删除。
3. 标准答案明确列出多个形式时，逐个结合上下文整理。括号可能表示上下文、备选形式或可选成分；斜杠也需依据原文处理，不能统一套用一种规则。
4. 生成候选后与上下文拼接检查，不得改变否定、代词所指、语义、重音或时态。多个解释均可能成立、映射不清或证据不足时标为待核对，保留原文供检查，不生成猜测的正式判分形式。
5. 将逐项整理的形式、证据和确定状态固定为版本化数据；考试创建时与题目一起冻结。运行中不临时按相似度猜测或调用不可追溯的语义模型判分。

## 三、具体案例与处理方向

| 题目 | 题面及标准答案 | 应核对的空内形式 |
| --- | --- | --- |
| 2023-V01 | 题面已有 Je，标准答案 `J'ai éteint` | `ai éteint`；需处理主语省音与题面展示的关系 |
| 2023-V02 | 空后已有 `à`，标准答案 `me suis mis à` | `me suis mis` |
| 2011-V01 | 题面已有 `je`，标准答案 `(j’) attendais` | `attendais` |
| 2008-V18 | 动词提示包含 `me faire asseoir`，标准答案 `(m')a fait asseoir` | `m’a fait asseoir`；不能把动词提示中的 me 当作正文已出现而删除 |
| 2018-V05 | 题面已有 ne，标准答案 `(n’)en avait` | `en avait`；不能连 en 一起删除 |
| 2019-V09 | 空后已有 déjà，标准答案 `ai (déjà) taillés` | `ai taillés` |
| 2017-V04 | 标准答案 `satisfît / satisfasse` | 分别记录 `satisfît`、`satisfasse` |
| 2007-V14 | 指定原答案与现有题面映射存在冲突 | 先核对题面位置与空内形式，不根据字符串相似度强行推断 |

示例是对当前题面及参考的处理方向；上线前应逐项核对原题、映射和版本。对于题面显示 `je` 而法语完整句需要 `j'` 的情况，输入框规则应明确接受何种空内写法，不把题面排版问题转嫁给用户。

## 四、用户作答的比较和结果

- 只比较该题已确认的空内形式及明确允许的其他形式。规范 Unicode 组合形式、首尾及重复空格、大小写、直弯撇号；保留法语重音和有语义的否定词、代词、连字符。
- 空白或纯空格是未作答；有确认答案且匹配为正确；有确认答案但不匹配为错误；答案、空位映射或处理状态尚不能确定时为待核对，不直接记错。
- 允许的完整短语或冗余上下文形式应在题目规则中明确记录，不能默认接受任意额外词语；特别避免将 `ne...pas` 中的否定部分当作无关内容。
- 报告展示用户作答、标准答案及结果；必要时说明接受的空内形式。正确、错误、未作答、待核对分别统计；待核对不写入确定错题。

## 五、快照、旧考试与数据回流

新考试冻结题目、材料、标准答案、空内形式、规则及版本；交卷、报告和作答事件使用同一份冻结数据。继续中的考试按原快照处理，历史报告和成绩不静默重算。题库修订后创建的新考试使用新版本。用户、考试和题目维度保证提交与事件幂等；错题记录仅接收明确判错的作答。
