# 动词填空：基于实际题库的判分规则设计

状态：规则设计，待逐题核验和实施
日期：2026-11-03
依据：21场420空的本地题库、用户确定的当前答案版本及现有修订。标准答案是用户确定的最终版本；以下工作用于确定每个空内可接受的输入，不重新裁定标准答案。

## 真实数据盘点

已按当前题库中的题号提取420个空位的前后上下文、当前答案和已列出的其他形式，保存在[逐空上下文清单](../output/verb-grading-audit/420空上下文盘点.csv)。基于简单文字模式的初筛提示15项可能有空前重复或省音；这只是线索，不是错误数或覆盖全部问题的证明。例如 `à` 与 `au` 的缩合、题面提示括号、参考答案内的多个形式都不能依靠本次简单匹配穷尽。

39个含括号或斜杠的答案此前已经逐项分类并形成当前40项空内形式修订；其余答案并不能因不含括号而自动视为空内文本。当前实现仍使用 `verb-exact-v1`，对未列出的空内形式会判错。

## 规则一：明确空位及题面已有内容

1. 在固定版本的文章中，根据题号找到唯一空线，记录其前后原文、紧邻词、对应题号及材料版本。无法唯一定位时状态为待核对。
2. 区分句子里真正已经显示的文字和 `(动词原形)`、`<u>`、`**`、题号等提示和排版；动词提示不是空前已经出现的正文。例如2008-V18的 `(me faire asseoir)` 是提示，不能因其中有 `me` 就删除答案中的 `m’`。
3. 对答案中的主语、宾语代词、否定词、介词及副词，逐项记录它在题面的位置，而不是统一移除。2021年5月题面含省音提示括号，须与正文区分并保留原始证据。

## 规则二：空前重复与省音

当标准答案开头的成分已在空前正文中显示时，记录与其对应的空内形式。省音需要考虑完整句子而非简单字符串删除：

- 2023-V01：题面 `Je (J') (éteindre) [空]`，标准 `J'ai éteint`；空内候选 `ai éteint`。
- 2005-V10：题面 `on me (dire) [空]`，标准 `m'a dit`；空内候选 `a dit`，`me` 是空前正文。
- 2013-V01：题面 `ils la (amener) [空]`，标准 `l’ont amenée`；空内候选 `ont amenée`，需检查题面和省音显示。
- 对比 2005-V01：题面是 `Je (s'appeler) [空]`、标准 `m'appelle`。`Je` 并不等同 `m’`，不能删去反身代词；只因出现省音而删除会误判。

这些是基于当前题面的待核对处理样例，必须结合原卷和显示规则确认；不引入全局“删代词”规则。

## 规则三：空后重复和介词缩合

标准答案结尾已由空后正文提供时，将与整句一致的空内部分记录为候选。直接重复和缩合分别审查：

- 2023-V02：标准 `me suis mis à`，题面 `[空] au travail`。`au` 含有 `à + le`，空内应核对 `me suis mis`，不能再要求输入 `à`。
- 2019-V09：题面 `[空] déjà dimanche`，参考 `ai (déjà) taillés`；整理为空内 `ai taillés`，不重复要求 `déjà`。
- 2021-06-V18：题面 `[空] déjà ...`，参考 `avait (déjà) dépensé`；整理为空内 `avait dépensé`。
- 2014-V13：题面已有 `toujours`，标准 `avait toujours été`；空内 `avait été`。修复依据和原答案均保留。

处理 `à/au`、`de/du/des`、`le/la/les` 时必须结合整句和每空位置；相似拼写不构成自动删词证据。

## 规则四：多答案、括号和空前后关系

- 2017-V04 的 `satisfît / satisfasse`、2017-V07 的 `fût / soit` 分别保存两个明确形式；2018-V14 的 `fussent (soient)` 同理。
- 2008-V12 的 `(j')aie fait (fasse)` 同时涉及主语和多答案，应逐一建立空内 `aie fait`、`fasse` 并保留标准答案原文。
- 2021-06-V17 的 `(d’) avoir mis / mettre` 要结合空前 `de` 分别核对形式，不能把括号和斜杠一起机械删除。
- 2007-V14 的指定来源与当前题面存在冲突：目前派生答案是 `est`，原指定文本为 `(m')étant`。当前版本虽已按用户决定作为标准，题面与空位对应仍需列为映射核对项目；不得在运行时猜测或无记录地替换标准答案。

## 规则五：判定和文本规范

逐题维护：标准答案原文、最终答案版本、题面上下文版本、确认过的空内形式列表、派生原因和证据、状态与规则版本。标准答案展示与判分输入形式分离；新增接受形式是标准答案在题面空位的表达，不抹去原文。

比较允许 NFC Unicode 规范化、大小写、首尾/重复空格和直弯撇号；保留重音、否定、代词和有意义连字符。未答为空；已确认答案集匹配为正确，不匹配为错误；空位或映射未确认则待核对，不将其写为确定错题。是否额外接受用户输入的完整短语须逐题明确，不默认允许插入多余内容。

不采用运行时任意语义相似度、模糊字符串或机器自由生成答案作为直接判错依据。可以批处理生成候选，随后逐项验证并冻结；低置信度、多个可能空位或上下文不完整不能自动升级为已确认。

- [ ] 先覆盖上文重复/省音/缩合/多答案和否定反例；为每个规则同时验证应接受和应拒绝的输入。
- [ ] 新建Mini冻结确认后的空内答案和规则版本；不改变旧考试快照、历史报告或成绩。
- [ ] 题面不完整、答案映射不明或多个可能空位必须待核对；检查报告与错题事件不会将待核对或未答记作错误。

本文件描述规则和验收条件，不表示420项映射已完成或自动判分已经达到可靠验收标准。现有本地判分实现和线上发布状态另行说明。
