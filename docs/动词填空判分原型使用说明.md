# 动词填空判分原型

这是填空判分模型 v1.0 的命令行预览，使用与新建 Mini 相同的判分函数及当前本地题库和答案版本；预览不提交考试、修改成绩或写入错题。需 Node 24，在项目根目录执行：

```bash
node scripts/verb-grading-prototype.mjs 2023-V01 "ai éteint"
node scripts/verb-grading-prototype.mjs 2023-V02 "me suis mis"
node scripts/verb-grading-prototype.mjs 2017-V04 "satisfasse"
```

输出包含结果、输入、标准答案、已整理形式、上下文、匹配原因和映射状态。大小写、空格和直弯撇号规范化，保留重音。空白为未作答；已记录形式匹配为正确；已有整理形式不匹配为不匹配；空位不唯一或未整理形式不匹配为待核对。

本原型不自行生成或核验尚未整理的空内形式，不等同于420项已逐题核对。新建 Mini 使用同一个 v1.0 判分函数；已创建考试继续使用其快照中的原规则。已创建考试使用自身快照。
