# 已审核题库

2026-10-27新增主页入口“已审核题库”，供管理员浏览内容审核已经通过的题目。

- 年份与题型可组合筛选，也可选择全部；显示已审核总数、筛选题数及页码，每页25题，所有结果均可翻页查看。
- 点击“查看题目详情”，按需读取选项、指定参考答案、解析及完整阅读/听力材料；同一时间展开一道详情，切页或离开时停止详情音频。
- 内容审核通过后自动收录，无需AI分类、来源确认或关联发布。未审核和已退回题目不显示。缺少解析的已通过题目可以显示，明确标注暂缺解析。
- 同来源同题多版本只显示最新已有审核决定的版本；新版本还未审核时保留此前已通过版本，新版本退回后不回落展示旧版本。单纯AI分类更新继承内容结果时不重复展示。
- 普通考生不提供此管理入口，后端同样检查管理员身份，避免公开可直接读取答案的接口。

接口为`GET /api/admin/bank/approved?year=2025&typeId=grammar-choice&page=1`，筛选项均可省略。列表只返回概要与筛选项；详情接口`GET /api/admin/bank/approved/:importId/questions/:questionId`重新核对当前审核状态，已经退回或被新审核版本替代时返回404。

本轮无数据库结构变更，不修改考试来源、历史报告或线上数据。新增3项自动测试覆盖年份/题型、分页、材料、版本去重/撤回及权限；整套47项自动测试、40项阶段2浏览器检查通过。多年份浏览器测试使用临时库中的合成年份，不代表已导入第二套真实年份。
