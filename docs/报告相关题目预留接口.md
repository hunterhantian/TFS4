# 报告“相关题目”预留接入约定

2026-10-27状态更新：阶段2本机已通过该接口接入已审核关联查询，开发自测完成、待用户验收。真实2025候选仍未审核发布，所以显示无已发布关联是预期结果；线上仍为Stage1。实现及权限见[阶段2JSON导入约定](阶段2JSON导入约定.md)。

以下为Stage1设计记录：当时仅预留展示区域与挂载接口，没有推荐数据或匹配算法，默认显示“待接入”。

## 调用方式

`web/modules/views.mjs` 的 `renderReport(report, options)` 保持单参数兼容，可选传入：

```javascript
renderReport(report, {
  mountRelatedQuestions(container, context) {
    // 仅在用户打开一道题后调用；container是该题“相关题目”的内容节点。
    // 后续模块可在这里创建入口并按需读取已审核关联，不要改写原题或报告。
    // 返回清理函数，用于停止异步任务、移除监听器等。
    return () => {};
  }
});
```

context是只读对象，包含questionId、questionVersion、sourceId、sourceRevision、reportId、attemptId。问题和答案来自该存档的冻结快照，不用当前题库覆盖历史。

## 生命周期与权限

- 初始不生成任何题目详情节点；同一报告最多存在一条详情行。
- 点击另一题、再次点击当前题、折叠所属Part、切换页面或退出登录，会清理已挂载内容；详情内挂载资源清理，旧详情行从DOM删除。听力音频已移到Part级共享播放器，不属于题目详情；切换/收起单题不会影响其播放进度。
- 挂载函数同步返回可选清理函数；如需请求网络，后续模块自行用AbortController等在清理时取消，不得在已移除节点上继续写入。
- mount失败只让该预留区显示“暂不可用”，不影响成绩表。
- 此接口只是前端接入点。后续服务端仍须检查报告归属或管理员只读权限，并按产品要求仅推荐已审核题型/主考点关联、保持完整材料。不能因传入questionId/reportId就视为已授权。

## 当前题目详情

整行可点击，题号是支持键盘的展开按钮；显示冻结题干、选项，以及必要的材料/音频。标准答案绿色、用户错选红色，●标记用户选择、✓标记标准答案；用户选对时同时显示两种标记。材料长文默认折叠，听力Part级共享音频preload=none；没有把100题详情和音频全部预先挂进DOM。


听力共享播放器在Part标题下、表格上方；相关题组件的清理函数不得操作该共享播放器。折叠整个听力Part或离开报告时由报告页负责暂停，位置不因切题而重置。
