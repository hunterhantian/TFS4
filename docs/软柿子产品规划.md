## 一、产品目标与设计原则

**软柿子帮助用户通过持续测试发现错误，利用错题开展学习，再通过相关题训练提高成绩。**

核心循环：

**测试 → 记录错误与不确定 → 将错题交给外部 GPT 学习 → 同题型、同知识点训练 → 再次测试。**

所有功能围绕这个循环设计：

- 用户可以用 **30–45 分钟**完成一次训练，降低完整考试带来的压力。
- 每次作答保留答案、信心度、时间与结果，让错误可以追溯。
- 利用官方解析建立知识点关联，让一道错题能够找到其他相关题。
- 保留重复犯错和后续训练的数据，支持用户持续学习。
- 基于每次及一段时间的测试表现，评价听力、词汇、语法、阅读四项能力，展示综合与分项变化，并指向需要加强的练习。
- 前端保持轻量，支持电脑和 iPhone Safari。
- 系统负责测试、记录、关联、推荐与导出；学习材料由外部 GPT 设计。
- 提供有数据依据的分项能力评价与追踪；暂不建立细粒度知识掌握等级、知识盲区评分或复杂能力推断。

产品名称：**软柿子**  
副标题：**专注法语专四考试**

### 1.1 视觉信息原则

保持暗色底，并用鲜明、稳定的颜色帮助大脑快速区分不同信息。主题用紫色，日期用天蓝，时间用金黄，完成度用青绿，考试类型用玫紫；颜色结合字段标签、数字及图形，不单靠颜色传达含义。既有考试分项、正误和信心的颜色语义保持一致。

存档展示把主题、提交日期、提交时刻、完成度、真实考试类型拆成可直接读取的信息项。完成度按已答数/实际总题数计算，与答对数/正确率分开。缺失日期、时间或类型显示未记录。颜色用于关键文字、标签、边框与进度条，保持页面简洁和手机可读。

具体色值与后续页面复用约定见[界面信息配色规范](界面信息配色规范.md)。

## 二、题库与知识点关联

### 2.1 每套试卷保存的内容

| 内容 | 产品要求 |
| --- | --- |
| 试卷来源 | 年份、考试名称、原始文件 |
| 考试结构 | 听力、词汇、语法、阅读及其原始顺序 |
| 题目 | 题干、选项、原题号、题型 |
| 关联材料 | 阅读文章、听力音频及对应题组 |
| 官方答案 | 正确答案及来源 |
| 官方解析 | 解析原文及来源位置 |
| 知识点 | 主考点、辅助考点，以及匹配依据 |
| 关联题目 | 同题型、同知识点的其他题目 |

一道题可以对应多个知识点，但需要区分主考点和辅助考点。

### 2.2 机器主导题库生产与关联

**资料登记与分年分卷 → 所有文档强制最佳质量OCR → 助手全量对照原页校对修订 → 保存结构化JSON和修订记录 → 程序质量校验 → 机器校对通过内容入库 → 用户可选整批确认/退回。**

已有OCR、可搜索PDF和原生文字文档也要重新用最佳质量识别，不因能够复制文字而跳过。原始资料只读保留；全部OCR文档由助手校对一次，覆盖原题号、题干、选项、填空、重音、材料、答案和解析的原页对应。助手获授权完成常规纠错整理，无需用户逐字校对或逐题批准。

JSON保留来源与页码、原始OCR、校对结果、修改前后、问题和版本。机器校对完成与人工批次确认分别记录，不把一个“审核通过”按钮视为OCR及校对已完成。系统审核为轻量确认步骤，不作为用户必须逐题劳动的环节。

先完成2023、2024各一份完整原卷的最小闭环测试，验证强制Best生效、全量校对、JSON、去重、材料完整性和真实跨年匹配，再交由助手按此流程批处理全部题库。未完成或不确定内容保留具体问题，不伪造完成状态。

内容生产与AI关联分离：内容库成型后由助手在独立“AI关联维护”页面统一主辅考点、同义名及跨年份匹配。实验候选不直接进入正式推荐；只有经核对发布的关联用于推荐及按考点组卷。用户不手动建立关联。

用户指定参考答案继续用于判分；AI修复OCR与来源映射错误保留依据，不能把AI建议冒充官方答案或解析。资料本身冲突、低清和缺失项有独立状态。历史考试/报告和既有基础存档不被新校对结果改写。完整规则见[Stage2机器主导题库生产流程](Stage2机器主导题库生产流程.md)。

### 2.3 关联查询

2026-10-28用户确认：**以知识点展开，题型作为分组和训练顺序。** 用户从知识树具体主知识点直接展开多道客观题，按题型分组；同题型先巩固，其他题型后应用。标注只做到题目自身的知识点归属、题型及必要依据/复核，程序查询形成列表，不逐对标注题间关系。新增已标注题不重标同组题。作文/看图等主观任务不进入后续匹配范围。详见[Stage2匹配原则](Stage2匹配原则.md)；正式节点多题页面尚待开发，下列从单题出发的能力作为其详情入口保留。

用户可以从一道题或一道错题，找到：

- 同题型、同主考点的其他题。
- 这些题目的年份和来源。
- 对应的官方解析。
- 自己是否做过、是否做错、最近作答结果。

阅读与听力的关联推荐必须保留必要材料，不展示脱离上下文的孤立题目。

## 三、测试模式与作答体验

### 3.1 测试模式

| 模式 | 内容 | 时长与题量 |
| --- | --- | --- |
| 完整真题 | 某一年完整的已数字化客观题范围 | 保留原卷结构，允许分次完成 |
| 听力专项 | 历年听力，按材料与题组组织 | 目标 30–45 分钟，题量随音频和题组调整 |
| 词汇专项 | 历年词汇题 | 目标 30–45 分钟，按预计用时组卷 |
| 语法专项 | 历年语法题 | 目标 30–45 分钟，按预计用时组卷 |
| 阅读专项 | 历年阅读，保持文章和题组完整 | 目标 30–45 分钟，按材料组织 |
| Mini 测试 | 不含听力 | **20 题：词汇 5 题＋语法 10 题＋阅读 5 题，阅读为完整一篇** |
| 错题专项训练 | 原错题重练或关联新题训练 | 支持短训练，目标 30–45 分钟；题量不足时如实提示 |

短测试的 **30–45 分钟是建议时长**，不是自动交卷期限。允许暂停，超时后仍可继续，并保存实际用时。组卷依据预计时长，不能保证每个人都在同一时间完成。

完整真题本期也允许暂停和分次完成，严格限时模拟考暂不加入。

### 3.2 组卷规则

- 普通专项默认跨年份抽题，也可指定年份范围。
- 同一份测试内不重复抽取同一道题。
- 阅读、听力按完整材料题组抽取，保留组内顺序。
- 题量或材料不足时显示实际可用范围，不静默重复题目凑数。
- 创建测试后固定题目与顺序，刷新、暂停和换设备继续时不重新抽题。
- Mini 测试缺少完整五题阅读材料时，提示无法按当前规则组卷，不拆散其他材料强行凑足。

### 3.3 作答体验

- 保持暗色主题，沿用“软柿子”品牌与轻快布局；使用鲜明且固定的语义色区分信息，详见界面信息配色规范。
- 在题目下方直接选择答案。
- 下方选择 **🟢肯定／🟡犹豫／🔴猜测**。
- 信心度可不选，报告表格以灰色空心圆表示未记录；提示及无障碍标签保留含义，信心度不改变考试成绩。
- 2025完整考试为12个纯数字导航按钮，考试标题中法双语并明显展示；后续其他试卷页数按实际结构确定。
- 关联分页目标为每页 5–15 题，优先保持题组完整。
- 提供“暂停并保存”和“继续考试”。
- 听力专项提供音频播放；本期允许用户主动暂停、重播，记录听力材料的实际用时。
- 交卷前可检查漏答；允许确认后提交不完整测试。
- 作答过程中不显示正确答案与解析，提交后查看。

### 3.4 计时与恢复

- 保存测试总有效用时。
- 所有题目按选择答案的有效时间间隔自动累计作答时间（2026-10-26用户体验修订）。
- 阅读、听力等同时保存材料题组用时；单题时间来自实际选答间隔，不是对材料时间的平均分摊。
- 不再手动设置当前题。打开题组即自动计时，按答案选择间隔归属到本次作答题；信心选择不切换计时目标。暂停/换页/交卷时结算当前间隔。
- 暂停、退出或页面切到后台后停止计时；听力也随之暂停，返回后由用户继续。
- 本机即时保留答案、信心度、位置和计时状态；服务器每5分钟常规同步，不因单题选择或换页逐次同步。暂停、交卷、离开/后台、重连及恢复等关键边界即时同步，服务器未确认时不得显示已保存。
- 同一账号跨设备可恢复；同一份测试只允许一台设备处于作答状态。
- 未记录的历史耗时显示“未记录”，不填成零。

## 四、存档、报告与错题学习循环

### 4.1 考试存档与报告

每次交卷自动形成独立记录，以考试主题＋提交时间命名，保留：

- 测试模式、来源年份、开始与提交时间。
- 实际题量、已答题量、总用时。
- 原始作答、信心度、逐题或材料题组用时。
- 正确答案、官方解析、题型及知识点。
- 正式 Part 和材料题组的统计。

报告同时显示：

- **整份测试正确率：答对数／总题数。**
- **已答题正确率：答对数／已答题数。**
- 未作答数量；未作答不自动计入错题本。
- 各 Part 的相同统计口径。
- 每题正误、错题标记、信心度和耗时。

自定义试卷和专项测试按实际题量计算，不固定显示“满分 100 题”。

**Stage1已交付的展示与交互：**

- 历史记录按主题、提交日期、时刻、完成度、考试类型分色；完成度为已答/总题数，与正确率分开。时间统一按上海时区展示。
- 可筛选最近一周、上周、最近30天、全部时间、自定义时间；自定义包含起止日。管理员可组合考生条件，普通用户仅查看本人。
- 报告按听力·Compréhension orale、词汇·Compétence lexicale、语法·Compétence grammaticale、阅读·Compréhension écrite分区，沿用Part II/III/IV/VI。四张同色总览卡显示答对数及进度条，点击定位对应表格。
- 表头固定为题号、完成、你的答案、正确答案、信心、作答时间。完成✔表示已答、×表示未答，答案颜色另行区分正误。信心只显示彩色圆点，未知用灰色空心圆；缺失用时不伪装成零。
- 点击题目显示冻结题面、材料和选项，正确答案用绿色勾选，错选用红色标记。全报告同时只展开一道题，切换时释放上一题详情。
- 题目详情预留“相关题目”挂载与清理接口；阶段2本机已接入已审核关联查询，未审核时显示缺少已发布关联；相关训练仍待阶段4。
- 听力Part标题和题号范围下放一个共享播放器；展开或切换题目保持播放进度。折叠听力Part暂停并保留当前位置，离开报告暂停；跨刷新位置恢复暂不实施。
- 管理员可只读查看所有已提交存档及归属，不能因此修改他人作答、报告或读取其未交卷进度。

上方官方解析、题型知识点、自定义试卷及专项测试是目标产品要求；Stage1仅交付现有2025客观题完整考试及可追溯答案快照，官方解析整理、知识点关联和其他测试模式不冒充完成。

### 4.2 信心度与结果交叉分析

| 作答表现 | 产品处理 |
| --- | --- |
| **肯定但答错** | 高优先级提醒，优先进入错题复习 |
| 犹豫或猜测且答错 | 进入普通错题复习 |
| 犹豫或猜测但答对 | 单独列为“待巩固”，可进入后续训练 |
| 肯定且答对 | 正常保留记录 |
| 原错题答对，相关新题也答对 | 展示这两类作答证据，不直接授予“已掌握”等级 |
| 未选择信心度 | 仅按正误记录，不猜测用户把握程度 |

### 4.3 错题本

错题本同时保留“题目汇总”和“每次错误事件”。

每道错题可以查看：

- 首次做错、最近做错时间。
- 每一次做错的时间、所属测试和当时选择。
- 每次作答的信心度与耗时。
- 累计作答次数、错误次数。
- 后续重练与关联训练结果。

同一道题后来答对，**原来的错误历史仍保留**。错题本不因一次答对而自动删除题目。

支持按考试部分、题型、知识点、来源年份、错误时间和信心表现筛选。

### 4.4 错题训练与相关题推荐

提供两个明确入口：

1. **原错题重练**：重新回答选中的错题。
2. **相关新题训练**：寻找同题型、同主考点的其他题，优先不同来源和用户未做过的题。

推荐规则：

- 先匹配已审核的题型与主考点。
- 排除原错题本身，优先未做题，再考虑做过的相关题。
- 同优先级内优先不同年份，随后随机选择。
- 材料题连同完整材料题组进入训练，并标明主要推荐目标题。
- 没有足够相关题时如实显示，不自动降低到关联很弱的题。
- 保存“这次训练源自哪些错题”，让后续结果可以追溯。
- 每次训练中的新错误继续进入错题本，形成下一轮循环。

#### 同考点训练后的延后混合测试

训练安排采用：**错题学习 → 同考点新题训练 → 隔几天后的 Mini 混合测试**。

- 同考点专项用于巩固；后续混合测试用于检查用户在没有明确考点提示时，能否自行识别并运用相应规则。
- 保留同考点训练完成时间，以及后续混合测试与该轮训练的关联，便于查看前后表现。
- 用户可在完成同考点训练后，将后续混合测试加入待练列表；显示训练日期和“建议隔几天再测”，不强制固定间隔。
- 混合测试遵循已有 Mini 规则，混入该轮已训练考点的不同题目及其他考点题目；作答前和作答中不标出哪些题对应先前训练，也不显示逐题知识点标签，提交后再展示关联结果。
- 关联题仍须满足已审核题型与主考点、材料完整和同卷不重复的规则；题库不足时如实说明，不用原题冒充相关新题。
- 本期只保留上述训练安排、时间和前后关联，不增加复杂间隔算法、自动提醒或新的测试模式。听力专项后的混合验证不通过 Mini 实现，因为 Mini 明确不含听力；本项不改变既有 Mini 范围。

### 4.5 与外部 GPT 配合

系统提供**错题学习包导出**，供用户交给其他 GPT 设计学习材料。

导出内容包含：

- 题干、选项、必要材料。
- 官方答案与解析。
- 题型、知识点。
- 用户错误选择、信心度、耗时。
- 错误时间线及后续训练结果。

用户可导出选中错题或筛选后的错题集合。学习包采用便于复制和阅读的文档形式，不包含账号凭据或无关个人信息。

本期不在系统内生成、存储或组织 GPT 学习课程，也不要求用户将学习材料回传。完成外部学习后，用户回到对应错题或题组发起训练。

### 4.6 用户能力分析与追踪（核心功能）

目标：用户能够知道当前听力、词汇、语法、阅读的测试表现，直观看到一段时间内的变化，并知道为了提高分值应优先练习什么。

#### 能力评价

- 每次测试完成后，展示本次覆盖分项的表现；对选定时间范围内的历史测试进行加权汇总，形成四项近期能力评价。
- 评价同时显示统计时间、有效测试次数、题量、不同题目数量和来源，能够追溯到具体测试与错题。
- 加权计算考虑有效题量和测试时间；不同题量的测试不简单按每场等权平均。具体时间衰减、权重、最少样本和评价文案在实施前审阅确认，界面提供计算口径说明。
- 保留信心度与正误的交叉分析，作为练习优先级依据；未经另行确认，不把信心度或耗时直接混入能力分，不改变考试成绩。
- 未覆盖的分项显示“暂无数据”；例如 Mini 不含听力，不能据此产生新的听力表现或将听力记为零。
- 未完成测试的漏答、答案待复核题和导入记录的数据缺失单独标注，并明确其是否参与计算；不能把缺失字段视作已测能力。
- 分开标识普通测试、原错题重练和定向训练。重复原题的训练成绩保留展示，但不能不加区分地累计成综合能力提高的证据。

#### 综合能力与趋势图表

- 提供一个轻量的“能力追踪”页面，展示综合表现、听力、词汇、语法和阅读五个趋势。
- 支持按每次测试查看，也支持最近 7 天、30 天、90 天及自定义时间范围。
- 使用折线图显示随时间的变化；使用四项对比条形图展示当前强弱项。手机可切换查看分项，不依赖鼠标悬停读取数值。
- 点击图表数据点可查看日期、统计分值、样本量、计算依据及对应测试。
- 综合指标按固定且公开的分项权重汇总，不随用户近期更常练习哪个分项而自动改变权重。目标考试分值权重尚未确认时，不将自定义指标称为官方成绩预测。
- 四项数据不齐时，优先展示已有分项并说明综合评价暂不可用，不对缺失项补零或默默重新分配权重。
- 比较同一统计口径的历史区间，显示上升、下降或变化不大；数据稀少或分项数据陈旧时提示，不强行给出能力变化结论。
- 第一版属于基于测试表现的统计评价，尚未校准不同试卷难度，不将其宣称为标准化能力测量或保证可达的真实考试分数。

#### 提分方向与练习入口

- 根据近期分项表现、目标试卷分值占比、错误分布与信心表现，展示优先加强的分项及相关题型、知识点。
- 将“较薄弱且在目标考试中占比较高”“肯定但答错”“多次做错”等可解释依据展示给用户，不仅给出抽象分数。
- 目标分值权重未核实时，明确只依据表现和错题推荐，不伪造可提升分数。
- 每条建议可直接进入对应专项测试、错题筛选或已审核关联题训练；匹配不足时如实说明。
- 完成训练及后续测试后更新图表，并保留历史结果，帮助用户观察练习方向与后续表现的关系，不保证练习一定带来固定提分。

#### 数据口径与历史可追溯

- 原始考试成绩保持独立、不覆盖；能力分析是其上的统计视图。
- 保存统计规则版本及参与记录范围。调整权重或算法后，图表比较使用同一版本重新计算，明确标注，不能把算法变化冒充能力增长。
- 能力数据仅本人可见，遵循考试记录的账号隔离规则。
- 本功能扩展的是听力、词汇、语法、阅读层面的评价，不恢复此前暂缓的逐知识点“已掌握”等级和知识盲区评分。

## 五、页面结构、交付顺序与验收

### 5.1 用户前端

主要页面保持精简：

- **首页**：选择完整真题、专项或 Mini 测试，继续未完成测试。
- **考试页**：材料、题目、信心度、计时、暂停和交卷。
- **考试记录**：历史列表与报告。
- **错题本**：筛选、查看错误历史、导出学习包、发起训练。
- **能力追踪**：查看综合及四项能力趋势、样本依据和提分练习方向；首页提供简短摘要和入口。

题库导入和知识点审核属于管理员操作，不进入普通用户答题流程。

### 5.2 开发顺序

| 阶段 | 可验收成果 |
| --- | --- |
| 第一阶段：可靠保存（已收尾） | 基础账号、隔离、自动计时与5分钟同步、暂停续答、云端存档、筛选、六列报告、共享听力、备份及腾讯云部署；含开发中逐步优化功能 |
| 第二阶段：题库关联 | 2025 年资料整理、官方解析入库、统一题型和知识点、AI 候选关联与批量审核 |
| 第三阶段：短测试 | 听力、词汇、语法、阅读专项，以及 20 题 Mini 测试、手机端体验 |
| 第四阶段：错题循环 | 错题时间线、信心度交叉分类、学习包导出、原题重练、关联新题训练 |
| 第五阶段：能力分析与追踪 | 单次及阶段加权评价、综合与四项趋势图、可解释提分指引、关联练习入口 |

先让 2025 年题库跑通完整流程，再批量加入其他年份。历年专项测试需要相应年份的材料、答案和解析已完成导入。

能力分析需要的测试时间、题目版本、正式分项、作答正误、训练来源和重复题标识，从第一阶段就保留；图表与提分指引在基础数据可靠后交付。

### 5.3 核心验收场景

- 导入一套带官方解析的试卷，能追溯每个知识点关联的依据；未审核关联不会用于推荐。
- 创建 Mini 测试，得到词汇 5 题、语法 10 题、完整阅读 5 题，且没有听力。
- 暂停或换设备后继续原测试，答案、信心度、顺序和有效用时保持一致。
- 同一道题在不同测试中两次做错，错题本保留两个准确时间点。
- 肯定但答错得到优先提醒；猜对的题出现在待巩固列表。
- 从错题发起关联训练，推荐同题型、同主考点的新题；匹配不足明确提示。
- 关联训练后能查看原错题与新题的结果，历史错误不会因答对而消失。
- 完成同考点训练后可安排隔几天的 Mini 混合测试；题目混合呈现且无考点提示，提交后能追溯相关训练及结果，Mini 题量与不含听力的规则保持一致。
- 导出的错题学习包能够独立提供给外部 GPT 使用。
- 普通用户不能查看其他用户的考试与错题记录。
- 单次与时间段评价能追溯到参与测试及有效题量；不同题量不会被不加区分地按每场等权平均。
- Mini 测试不新增听力表现，四项不齐不伪造综合分；缺失或陈旧数据有明确标记。
- 同题重练与普通测试区分展示，原题反复答对不会直接冒充整体能力提高。
- 综合和分项图表支持时间筛选、手机触控与数据点详情，口径变化有版本标记。
- 提分建议有明确依据，可以进入对应练习；新测试后更新能力视图而不改写原始成绩。

### 5.4 本期边界与既有事项

- 暂不做知识掌握等级、知识盲区评分、遗忘曲线或复杂自适应算法。
- 暂不做系统内 AI 教学、学习材料生成、主观题自动评分、付费及机构管理。
- 基础账号先由管理员创建，暂不提供公开注册。
- “完整真题”本期指已支持的客观题范围，页面明确说明覆盖范围。
- 用户确认系统现有存档为基础，已核验、备份并迁移云端，存档内容未改；云端副本仅清除登录会话。未定位的外部旧文件不冒充已导入，不作为当前阶段阻塞项。纸质答题卡识别仍未实现；考试存档已采用主题＋提交时间自动命名，取消手动命名要求。
- 本规划替代上一版产品规划。新增知识点关联、短测试、错题循环及能力分析追踪后，原 10–18 人日估算失效；后续按已确认产品范围重新评估。
