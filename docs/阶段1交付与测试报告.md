## 体验方式

本机独立入口：http://127.0.0.1:4174/ 。新界面与原静态原型端口4173分开，数据库、Cookie和本机缓存均不冒用旧原型记录。初始管理员账号已经生成，凭据仅保存在本机 `.local/stage1/体验账号说明.txt`，不进入Git、不在日志打印。

“服务器保存”在本次体验中指本机Fastify+SQLite服务持久保存，**尚不是已发布到互联网的腾讯云账号网站**。双设备测试使用独立浏览器上下文模拟；真正外网跨设备使用须先落实HTTPS和发布准备。

建议最终验收顺序：

1. 登录；在“账号管理”创建一个普通账号。普通账号只看到自己的记录，不能管理账号。管理员可重置密码，旧登录会话随之失效。
2. 开始2025完整考试，选择答案与信心，点击“设为当前题”查看标记。词汇独立题/语法独立题记录当前题用时；阅读、听力、词汇完形按材料累计时间，不强行分摊到单题。
3. 暂停并保存；刷新后继续，核对题组、答案、信心和累计用时。切到后台也会暂停；返回后手动继续，音频不自动播放。
4. 可在另一个浏览器或无痕窗口登录同账号：先暂停旧窗口即可正常继续；未暂停则提示设备占用，需要明确接管。旧窗口之后的保存被拒绝，原本机待同步内容保留。
5. 交卷前确认漏答；允许提交不完整考试。查看报告的全卷/已答正确率、未答、正式Part、逐题正误、信心、耗时及答案版本；修改标题后刷新核对。
6. 如有已导出的旧原型JSON，可在“导入旧本机存档”预览；先显示原始备份已保存、重复项和缺失字段/旧答案口径，再勾选说明并确认。没有真实文件时无需伪造迁移来通过其余验收。

## 运行、管理与恢复

```powershell
./scripts/task.ps1 install
node scripts/manage.mjs seed
node scripts/prepare-local-review.mjs
./scripts/task.ps1 dev
```

本机默认4174、仅监听127.0.0.1。已存在的体验账号不会自动重置。实际生产管理员通过`manage.mjs create-admin <username>`创建，密码从临时RSZ_ADMIN_PASSWORD环境变量读取，用后清除；不通过命令参数或Git文件传递密码。

```powershell
node scripts/manage.mjs backup .local/stage1/backups/manual.sqlite
node scripts/restore.mjs .local/stage1/backups/manual.sqlite .local/stage1/restore-new/app.sqlite
```

恢复目标必须不存在，工具拒绝覆盖；不直接复制正在写入的SQLite。数据库/备份不得位于web或dist目录。DB_FILE、BACKUP_DIR、PUBLIC_ORIGIN、AUDIO_FILE可由环境变量配置；NODE_ENV=production时PUBLIC_ORIGIN必须为HTTPS并使用Secure Cookie。

重复测试：`./scripts/task.ps1 test`；浏览器测试需设置PLAYWRIGHT_PACKAGE_ROOT为已安装Playwright的Node包根目录，再运行`node scripts/stage1-browser.mjs`。常规产品运行不依赖Playwright或Python。原静态原型用`./scripts/task.ps1 prototype`另在4173查看。

- 域名/HTTPS尚未确认，不开放公网账号。O01–O06仍未勾完成；本轮未改服务器、Nginx或线上网站。

- 音频跨刷新位置恢复不实施；Safari真机验证暂缓，遵循用户阶段0验收意见。手机尺寸Chrome不等于真机Safari通过。
- 真实旧完整记录与纸质答题卡识别存档未交付；没有发明真实记录。JSON导入只接收已知2025客观题旧原型格式，最多200份/700KB，其他来源需另作适配。
- 旧导入记录缺失字段保留null；原始时间和题面版本无法从旧JSON证明时明确标识，不反推或伪造。导入报告保留旧作答，但尚未给旧资料补生成可用于能力统计的事件；D39须审阅是否/如何纳入，不能默认作独立能力证据。
- 当前sources保存已验收2025原卷基准，attempts保存不可变JSON快照与可变进度，报告/事件/错误/账号使用关系表。正式题库版本/知识点审核在D16–D22规范化扩展；不把候选知识点自动发布，也不提供测试夹具生产导入。
- 进度冲突不会自动合并两个设备的不同选择；先保留本机内容并提供导出，再由用户明确读取服务器或接管。服务重启/网络/租约异常不能被当作“已同步”。
- 本地缓存不是服务器备份；服务器不可连接时新页面需要先恢复连接再确认账号，未同步缓存仍保留。HTTP本机体验使用非Secure开发Cookie，生产模式禁止用HTTP Origin登录。
- 阶段1不产生能力评分、短测试、错题推荐、知识点审核或定时提醒。
