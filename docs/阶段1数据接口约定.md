# 阶段 1 数据与接口约定 v0.1

状态：阶段0可执行基础；API 尚未实现，迁移由 D07 实施。时间统一 UTC ISO 8601，耗时为整数毫秒，未知值 null，不能补零。标识使用不包含个人信息的随机 ID。

## 数据关系

- users → sessions：管理员角色、带盐密码哈希、服务器端会话、过期时间；只通过 Secure/HttpOnly/SameSite Cookie 传递会话。
- sources → materials / question_versions → answer_versions：来源哈希、原题号、正式 Part、component(listening/vocabulary/grammar/reading)、type、题目与答案版本、工作/待复核/已核实状态及来源位置。版本发布后只追加。材料保持完整；原卷未数字化的 Part I/V/VII 不伪造成客观题。
- knowledge_points / aliases → question_knowledge_links：主辅关系、依据解析、审核状态、审核人及版本；只有 approved 可推荐。
- attempts：ownerId、mode、origin(ordinary/original_retry/related_training/delayed_mini)、status(active/paused/submitted)、createdAt/startedAt/submittedAt、effectiveMs、revision、leaseDeviceId/leaseExpiresAt；创建后固定题序。
- attempt_items：attemptId、position、questionId、questionVersion、answerVersion、formalPart、component、materialVersion；提交保留完整题面和答案快照。
- responses：attempt/item、choice nullable、confidence(certain/hesitant/guess/null)、effectiveMs nullable；材料计时独立 attempt_material_times，不分摊到单题。
- submission_results：attempt 唯一、原始答案/正误/漏答/待复核状态、样本来源；重复交卷返回同一 reportId。
- response_events：每次交卷的题目作答事件，保留 owner、时间、训练来源、同题既往作答次数及 priorEventId；只统计该次提交之前的已提交事件。未答不产生错误事件；error_events 对每个错误独立建档，后续答对不删除。
- training_sources：trainingAttempt → 来源错误事件/题目；related_training 的 completedAt 来自提交事务。
- practice_plans：owner、sourceTrainingAttempt、trainingCompletedAt、createdAt、status、后续 delayedMiniAttemptId；无强制到期日和自动提醒。后续 Mini 的 source links 保存目标考点及目标题，但仅报告可见。
- analysis_rule_versions / analysis_runs / analysis_run_events：规则版本、参数、参与事件范围和计算时间。D39 前不写入权重、不产生能力分；原始结果独立保留。repeat、定向和混合来源均可追溯。

## HTTP 行为（同源 /api）

所有记录访问首先按当前会话 owner 过滤；他人记录返回 404。管理员操作检查 role。请求和响应均不记录密码与完整作答。JSON body 限制大小，拒绝未知字段。

| 方法与路径 | 请求/响应和约束 |
| --- | --- |
| POST /auth/login | username/password；频率限制；成功轮换 Cookie；错误统一 401 |
| POST /auth/logout、GET /auth/me | 注销服务器会话；未认证 401 |
| POST /admin/users、POST /admin/users/:id/reset-password | 管理员创建或重置；重置使旧会话失效 |
| POST /attempts | mode、source/year、deviceId、幂等 requestId；固定题序，缺材料或 Mini 结构不足 422；同 owner/requestId 返回原实例 |
| GET /attempts/:id | revision、status、固定题面、当前作答、位置和计时；不返回答案、解析、知识点、目标题及训练来源详情 |
| PATCH /attempts/:id/progress | expectedRevision、deviceId、完整待保存 answers、position、effectiveMs、materialTimes；同事务校验 revision 与 lease 后递增 revision；409 REVISION_CONFLICT/LEASE_CONFLICT 不写入；未知耗时保留 null，已知计时不倒退 |
| POST /attempts/:id/pause | 同 progress 的版本和占用检查；原子保存并暂停、释放占用 |
| POST /attempts/:id/resume | expectedRevision/deviceId；取得占用；冲突需明确接管 |
| POST /attempts/:id/takeover | expectedRevision/deviceId、confirmed:true；轮换占用，旧设备后续保存 409 |
| POST /attempts/:id/submit | expectedRevision/deviceId/requestId、最终进度；原子保存、判分、结果、事件、释放占用；已提交直接返回原 reportId，不再次建档；新提交不完整需 confirmIncomplete:true |
| GET /reports、GET /reports/:id、PATCH /reports/:id | 仅本人；提交后答案和依据版本；标题长度限制；统计总题正确率及已答正确率，分项也用实际题量 |
| POST /legacy-import/preview、POST /legacy-import/confirm | D15 实现；预览与确认分离、原始文件先备份、哈希去重、缺字段 null、来源 legacy，不伪造完整存档 |

每个写请求以 origin/CSRF 校验和会话归属保护。幂等键按 owner+operation 约束；进度并发以 revision 检查，无服务端成功确认不得显示“已同步”。设备租期由服务端配置，心跳更新；过期后必须重新取得占用，旧 revision 仍拒绝。提交后的进度请求返回 409 ALREADY_SUBMITTED。

错误统一 `{error:{code,message},requestId}`；校验 400、未认证 401、权限 403、不可见 404、并发 409、题库不足 422、限流 429。响应不暴露堆栈或其他用户信息。

## 可执行边界

`server/contracts.mjs` 提供作答与来源基础校验及公开题面白名单。测试使用 `tests/fixtures`，内存 SQLite；任何磁盘数据库必须由显式配置指定到网站目录外。阶段0不创建账号服务、正式数据库和统计规则。
