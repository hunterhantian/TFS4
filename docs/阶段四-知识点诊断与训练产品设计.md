# 阶段四：知识点诊断与训练产品设计

状态：产品设计记录，待细化与开发
更新：2026-11-03

## 目标

通过考试和训练的作答记录，帮助用户发现需要加强的知识点，查看判断依据，直接开始针对性练习，并在之后查看不同时间的作答与训练变化。

主要流程：**完成考试或训练 → 收集作答证据 → 发现需加强的知识点 → 针对性训练 → 延后混合检验 → 查看变化。**

阶段四不设计能力值、掌握度分数、综合分或预测考试分数，也不设计这些数值的计算或历史曲线。题目数量、结果、日期和覆盖范围用于说明证据，并非能力评分。

## 一、知识点诊断主页

主页优先回答“我该练什么”，展示：

1. **当前重点**：优先建议加强的 3—5 个知识点，说明推荐原因，并提供“查看依据”和“开始训练”。
2. **知识树概览**：各大类中需要关注的方向、已覆盖范围和证据是否充足；未测试的节点明确标记。
3. **最近变化**：最近训练的知识点，以及不同题目、不同时期的作答和训练记录。

具体知识点可显示“重点加强”“继续巩固”“近期表现较好”“证据不足／尚未测试”等状态。状态由可解释、可追溯的证据支持；具体门槛在实施前确认并通过实际使用调整。一次错误不能证明完全不会，未测试不代表不会。

## 二、知识树诊断

沿用现有三层知识树：**大类 → 规则族 → 具体知识点**。用户逐层查看关注方向，并进入具体知识点了解：

- 不同题目的数量、各题作答结果和来源；
- 首次作答、原题重练、同知识点新题与延后混合测试；
- 最近练习时间及相关历史记录；
- 题面、参考答案和知识点关联的来源与状态。

一道题可能涉及多个知识点，呈现主要关联及其他可用关联；允许用户反馈题目、答案或关联可能有误。关联未核验时明确显示，不能把推测呈现为确定的错误原因。

## 三、个人作答历史

每次交卷后，把考试与训练的作答记录纳入用户个人历史，包括考试或训练类型、时间、题目、用户答案、结果、题目与答案版本、关联版本和来源，以及首次作答或后续训练类型。未答、动词待评及无法可靠判断的结果单独记录。

用户可以查看单次考试档案，也可以按时间查看某个知识点的题目与训练记录。原始考试报告保持当时冻结的内容和结果；若以后使用更新的答案或关联生成分析，应注明版本和依据，不静默改写历史考试、报告或成绩。历史数据补录须先确定可追溯规则，不默认批量重算。

## 四、弱点侦查与推荐

推荐时综合考虑不同题目的错误记录、跨时间反复出现的情况、近期表现、证据质量及可用训练题目数量。推荐必须说明依据，用户可下钻查看题目和作答。

“有反复错误、建议加强”与“证据不足、建议先测试”分别展示。系统不把一次答错、未作答或未经核验的关联直接等同于知识缺陷。

## 五、针对性训练

| 训练方式 | 用途 | 选题原则 |
| --- | --- | --- |
| 原题重练 | 再次回忆此前做错的题 | 保留原题、原结果和练习来源 |
| 针对性训练 | 用户主动选择知识点练习 | 优先同知识点、未做过及不同年份的题 |
| 弱点强化 | 系统根据作答证据推荐训练 | 从需关注的知识点中选取适合练习的题，并说明原因 |
| 延后混合检验 | 观察训练后能否自行识别和应用 | 混入其他知识点；作答前不提示目标题或考点，交卷后可追溯 |

从全部可用年份和题型中挑选满足条件的题目；题目、材料、答案或关联不足时明确提示，不靠重复或不可靠题目凑数。阅读、完形保留理解和作答所需的完整原文及题组；作答过程中不泄露答案。听力是否纳入混合检验需另行设计。

用户可把训练完成的知识点加入待练列表，在方便时再次检验。间隔可以给出建议，但不强制，也不默认自动提醒；具体天数、题量和混合规则待设计及验证。

## 六、训练存档与数据回流

训练沿用考试档案体验：支持暂停、保存草稿、恢复和交卷后查看报告。记录训练来源、题目与版本、作答、结果及相关原错题，支持新错误继续进入错题本；原有错误记录不因之后答对而删除。

训练数据再次进入个人历史，供后续诊断使用。原题重练、同知识点不同题及延后混合检验分别展示，不把重复刷同一道题视为多道不同题的证据。按选中或筛选内容导出 Markdown 学习包的需求予以保留。

## 七、答案和证据边界

2026-11-03 交接记录：21 场新建考试的选择题采用用户指定的 `user-reference-v1`，交卷后可显示对错；420 个动词参考答案已接入查看与新建 Mini，动词文本题仍待评。部分选择题由解析补充，部分动词参考和知识点关联仍需核验。

区分可以用于判断的作答证据与待核验线索，呈现答案、关联和来源状态。用户指定答案可用于当前选择题判分，但判分结果与知识点关联是否可信是两个问题；缺答案、多解、未作答和待评不得伪装成确定错误。具体证据分层和用户反馈规则实施前结合实际数据确定。

当前 Stage 3 的听力、Mini 和完整客观题交卷尚不写入错题事件。阶段四先完成作答与错误事件衔接，并确保用户隔离、交卷幂等、版本可追溯及既有档案兼容。

## 八、建议实施顺序

1. 盘点现有作答历史、答案及知识点关联的覆盖和状态。
2. 建立个人作答与错误记录，衔接现有考试和后续训练。
3. 实现知识点诊断主页、知识树下钻和历史证据查看。
4. 实现针对性选题、训练存档及作答回流。
5. 实现弱点强化和延后混合检验，检查题量、去重和材料完整性。
6. 在实际使用中检查推荐依据、证据质量、用户隔离、暂停恢复和移动端体验。

本文件记录产品方向，不表示功能已完成。与既有研究及任务编号对应时，参见 [阶段四错题本与知识体检设计研究](阶段四-错题本与知识体检设计研究.md)和阶段四交接文档；如历史文档涉及能力值，以本次用户决定为准。
