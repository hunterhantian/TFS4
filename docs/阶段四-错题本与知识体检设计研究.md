# 阶段四：错题本、知识体检与进步报告

状态：阶段四产品研究与方向记录，待实施前细化、开发及用户验收  
更新：2026-11-02

## 一、目标和范围

用户希望通过不断测试收集学习中的知识薄弱环节，经错题复习、同知识点强化与延后检验，形成可以逐层查看、随时间追踪的“知识体检与进步报告”。**错题本、错题测试和基于知识树的体检及进步报告均归入阶段四。**

阶段四的报告聚焦知识树节点、对应题目及训练前后证据。阶段五原有的综合与听力／词汇／语法／阅读四项能力统计、固定权重、预测与趋势等工作仍保持原规划，具体口径和权重待阶段五确认；阶段四不因此声称完成阶段五。两者可共享经过确认的数据和来源，不能把某个知识点的证据直接冒充整项能力或官方分数。

以下属于研究支持的设计方向，不表示该功能、题库质量门或诊断模型已经实现、校准或验收。复习天数、题量、状态门槛等为初步设想，进入阶段四实施前需结合数据和用户体验确认。

## 二、研究与实际案例

1. **回忆并纠错：**Kornell 等比较了先尝试回答再学习答案与直接学习答案；实验材料中，即使初次提取失败，在获得反馈后仍可能促进后续学习。反馈应准确、来源可追溯，不把结果泛化为“猜错越多越好”。[Unsuccessful retrieval attempts enhance subsequent learning](https://pubmed.ncbi.nlm.nih.gov/19586265/)
2. **间隔和再次学习：**Cepeda 等比较了学习间隔与最终测试间隔，较合适的复习间隔会随保持目标变化；Rawson 与 Dunlosky 在概念材料实验中研究了初学及多次重新学习的组合。两者支持跨时间的反复回忆，不证明一个适用于所有法语题目的固定复习表。[Cepeda 等](https://doi.org/10.1111/j.1467-9280.2008.02209.x)、[Rawson 与 Dunlosky](https://pubmed.ncbi.nlm.nih.gov/21707204/)
3. **间隔的形状不是定律：**Karpicke 与 Bauernschmidt 的实验发现，将重复回忆分散在更长的总时间有益，但没有证据表明递增、等间隔或递减的相对安排必然有一种最好。因此递增日程可作为可解释的初版假设，不宣称科学最优。[Spaced retrieval](https://pubmed.ncbi.nlm.nih.gov/21574747/)
4. **混合检验：**Rohrer 等在七年级数学课堂随机试验中观察到混合练习组的延后测试表现较好；该实验不等同法语专四效果，但支持在针对训练后探索将不同考点混合，让用户自行识别方法。[Interleaved mathematics practice](https://doi.org/10.1037/edu0000367)
5. **Duolingo：**2016 年研究使用语言学习数据拟合间隔复习模型，并开展线上对照；用户反馈某些技能衰退过快后，团队调整了模型。后续模型版本的次日活动留存在特定实验比较中提高，不等于学习成绩同幅提高，也不证明同一算法适用于本项目。[A Trainable Spaced Repetition Model](https://research.duolingo.com/papers/settles.acl16.pdf)
6. **知识追踪：**研究使用题目与知识技能关联及连续作答估计知识状态，也考虑会做却失误、不会却猜对等情况；观察结果不等同直接测出真实掌握度，关联质量及样本量很重要。[Knowledge Tracing: A Survey](https://doi.org/10.1145/3569576)
7. **Khan Academy：**其学习报告展示技能变化，掌握度挑战使用同一技能的多个问题更新状态；这是产品实例，不代表其规则可直接应用于法语专四。[学习进度报告](https://support.khanacademy.org/hc/en-us/articles/360032987591)、[掌握度挑战](https://www.khanacademy.org/khan-for-educators/resources/teacher-essentials/safety-privacy-and-additional-resources/a/mastery-challenges-course-mastery)
8. **ASSISTments：**43 所学校、2850 名七年级学生的随机研究，考察在线作业系统、题目反馈和教师培训的组合，观察到数学测试改善。不能把效果完全归因于报告，也不能直接推断法语效果。[Online Mathematics Homework Increases Student Achievement](https://doi.org/10.1177/2332858416673968)

## 三、错题本：保留事实及不确定性

- 收集每次作答事实，区分首次答错、原题重练、同知识点新题、延后混合测试、未作答与后续结果；记录时间、题目和答案版本、信心、有效用时、考试及训练来源。
- 已核验且可以可靠判分的错误进入错题本；未作答单独记录，不能一律认作不会；“答对但猜测／犹豫”可作为待巩固线索；“肯定但答错”可优先复查，但一次表现不是永久结论。
- 阶段二现有部分答案、题面与知识关联为候选；阶段三听力／Mini 按用户确认仅展示未经核验的候选答案对照，不自动判分或写正式错题事件。候选答案不一致、动词多解、答案缺失或知识关联未核验时，标记待核验，不伪造确定错误。用户自主标记或纠错可作为建议方向，实施规则另行确认。
- 原题多次练习不删除旧错误，不把同一题 10 次重复作答算成 10 道不同题。相关新题需清楚标明来源、可靠关联与题目版本，优先未做题及不同年份；不足时说明，不以原题或弱关联冒充。
- 阅读、完形等保留理解和作答所需的完整材料与题组；混合训练能否整组加入，以最终题量、题组完整性及用户体验设计为准，不能静默截断文章。
- 保留原计划的筛选、原题重练、相关新题、训练来源追溯及按用户选中内容导出 Markdown 学习包；导出包含必要的题目、材料、来源、答案状态及作答上下文，不包含账号凭据。

## 四、错题训练循环

推荐的产品流程：**发现问题 → 查看可靠反馈并理解 → 原题回忆 → 同知识点新题 → 延后混合检验 → 更新知识体检证据。**

| 阶段 | 首版可讨论的安排 | 行为与目的 |
| --- | --- | --- |
| 发现 | 提交考试后 | 将可靠错误、未答、猜对／犹豫及待核验分开呈现 |
| 理解 | 当天，用户方便时 | 查看题目、可靠答案及解释，用户主动决定何时开始训练 |
| 原题回忆 | 上次完成约 1 天后 | 先独立作答，再看反馈，判断对原题的再现 |
| 同知识点新题 | 前一轮完成约 3 天后 | 尽可能使用不同题目，验证是否能迁移 |
| 混合检验 | 前一轮完成约 7 天后 | 与其他知识点混合，不提前暴露考点或目标题，提交后可追溯 |
| 延后确认 | 前一轮完成约 14 天后 | 再次观察更长间隔后的表现 |

上述 1、3、7、14 天均以**上一轮实际完成时间**为起点，若恰好按时完成，则是初次学习后的第 1、4、11、25 天。它们是产品试行假设，非研究确定的最优天数；用户可稍后练习，逾期不连续堆叠练习或暗示失败。当前规划是用户主动加入待练与选择练习时间，不默认新增自动提醒或强制间隔。

- 原题再错：回看解析，安排较短间隔的后续复习；不能靠反复猜测认定掌握。
- 原题对但可靠关联新题错：保留该差异作为迁移待验证信号，同时允许纠正错误的题目关联。
- 延后混合答错：保留记录、建议复习；连续跨时间答对可降低练习频率，但不将“掌握”描述为永久不变。
- 开始前告知范围、题量、预计用时和可暂停。10 题／10—15 分钟仅是讨论示例，需按真实题组和作答数据验证，不作保证；不为了计时拆散材料或强迫交卷。
- 阶段三按年份固定拆五份的 Mini 与阶段四“针对训练后的混合验证”是不同用途。D45–D47 的混合验证若实施，必须单独说明来源和组卷规则；当前 5 份固定真题方案不能自动满足可动态混入考点的要求。听力混合验证是否另设模式、如何处理音频须单独设计，不将听力塞进现有 Mini。

## 五、知识体检与进步报告

### 5.1 结构与展示

- 根据可信题目与知识树关联逐级展示：**大类 → 规则族 → 具体知识点**。上层节点同时展示覆盖范围：已有证据的节点数／总节点数；未做、无可靠答案或关联的数据明确显示“暂无数据／证据不足”，不按零分计算。
- 首页先给用户可操作的重点方向，每项显示具体知识点、不同题目数、涉及测试／日期、首次与重复作答、最近结果、答案与关联状态；可下钻到题面、来源、答案和训练记录。
- 同一知识点在不同时间、不同题目上反复出现可靠错误，是应优先处理的较强信号。报告可称“重点加强”，不以一次错误或一个未核验候选标注断言“完全没掌握”。用户能够查看结论依据，并反馈题目、答案或关联可能有误。
- 同一题可能涉及多个技能；报告说明主要关联，避免声称单次作答确定唯一错误原因。信心、答题用时和用户自述可作为辅助线索；未经确认及验证，不把它们直接混入能力分数。

### 5.2 进步证据

- 分开展示首次题、同一原题重练、同知识点不同题和延后混合测试，展示每个阶段的题数、不同题数、时间与结果；不把原题重复练习直接视为迁移成功。
- 可选择时间范围并追溯记录，展示覆盖范围和样本量。时间比较需提醒题量、难度、来源和题目是否可比；样本不足时不宣称精确变化或整体掌握百分比。
- 已交卷未全答、未知答案、待复核关联、历史缺字段及很久未测试均单列；长期未测只表示近期证据不足，不推断已遗忘。
- 旧考试快照、历史报告和成绩不因答案、题目、关联或分析规则更新被修改、重判。分析可建立可追溯的版本化视图，任何重算应说明口径与来源。
- 示意文案：“最近 3 次测试涉及 5 道不同题目，其中 4 道错误；建议复习该规则。”这些数字仅为展示示例，不是诊断阈值或已验证的准确率。

### 5.3 可行动与可解释

提供“查看证据”“查看解析／学习材料”“开始针对训练”入口；对每个建议说明触发依据和数据状态。初版采用可解释规则并记录版本；暂不将缺少校准依据的算法输出包装成概率、诊断结论、官方分数或个性化遗忘曲线。积累可靠数据后再独立验证更复杂的知识追踪及个性化计划。

## 六、实施前提、边界与验收

1. 定义并核验可用的题面、答案、多解、材料和题目—知识点关联；明确候选与已核验的边界及用户纠错的处理。
2. 验证事件归属、首次／重做／新题／混合来源、快照和版本、不同题目数及分母；避免混用未答和错误、候选答案与正式判分。
3. 不同用户隔离；既有账号、考试、答案快照和历史报告不改写。导出或分析仅处理必要数据，遵循用户已授权的使用范围。
4. 先在隔离数据、已知题目和可靠参考上检验分类与计算；检查样本不足、重复题、多知识点、题量／难度差异、长期未测和版本变更。
5. 原错题、可靠同知识点新题、完整材料、训练与延后验证来源可追溯；题目不够时如实提示。
6. 报告须展示证据和覆盖范围，支持按知识树下钻及用户指出存疑；候选状态不被冒充为确定盲区。
7. 桌面与手机实际体验“查看错题 → 理解 → 训练 → 暂停／恢复 → 延后再测 → 对照报告”，并观察完成率、用时、跨时间新题表现与用户反馈；不以展示次数或短期留存替代学习效果。
8. 阶段四具体诊断阈值、题数、复习建议、结果文案和混合组卷细则应在开发／验收中结合数据确认，不把建议误写为已验证事实。
